# 2D-TopDown-Combat
A small-scale 2D top-down prototype developed to practice core Unity systems, gameplay programming, and game development fundamentals.

## Features

- Character movement and animation
- Enemy combat system
- Coin and item collection
- Multi-scene world navigation
- Portal-based scene transitions
- Camera follow system
- Health and damage mechanics
- Tilemap and Rule Tile environments
- Basic weapon system
- Particle effects for combat feedback

## Technologies

- Unity
- C#
- Git & GitHub

## Purpose

This project was created to practice gameplay programming, Unity systems, scene management, and general game development workflows.

## Current Progress
